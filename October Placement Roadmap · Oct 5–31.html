Daily rhythm — 2 DSA problems first (~2 h), then the day's CSE core (~2 h), a short side track (~1 h), then interview questions and revision (~45 min). If a problem is not solved in about 30 minutes, read the solution, understand it, and rewrite it from scratch tomorrow without looking.
The 10-step process for every DSA problem
  1. Read the problem
  2. Try independently
  3. Identify the pattern
  4. Write the approach
  5. Code in Python
  6. Test edge cases
  7. Analyse time complexity
  8. Analyse space complexity
  9. Review the solution if stuck
  10. Write a one-line takeaway

Each problem below has five tick boxes (Solve, Code, Test, Complexity, Review) plus a takeaway field that cover these steps. A problem counts as done when all five are ticked.
