# October SDE Placement Roadmap

A 27-day (Oct 5–31) campus placement preparation roadmap for SDE / Software Engineer roles, built as a single-page tick-and-track checklist.

**CSE fundamentals come first.** The month is built so you can answer campus interview basics clearly: processes, deadlocks, normalization, indexes, ACID, TCP vs UDP, OOP pillars and "what happens when you enter a URL".

## What's inside
- **Day-by-day plan** with the day's goal, CSE core concepts, side track, interview questions, a practical task, revision and a day-complete checklist
- **Exactly 2 DSA problems per day (54 total, Python)**, grouped by pattern: arrays and hashing, strings and two pointers, sliding window, stack and queue, binary search, linked list, trees and heap, graphs
- **210 interview questions** across DBMS, SQL, OS, CN, OOP, COA, Software Engineering, Python and Backend
- **Weekly mock tests** (Days 7, 14, 21) with a score and Strong / Needs revision / Weak status
- **Final assessment (Day 27):** nine timed rounds and a scorecard
- Progress saves in the browser, with backup, restore and reset

## Weekly focus
| Week | Dates | Focus |
|---|---|---|
| 1 | Oct 5–11 | DBMS, SQL, Python |
| 2 | Oct 12–18 | Operating Systems |
| 3 | Oct 19–25 | Computer Networks, OOP |
| 4 | Oct 26–31 | COA, Software Engineering, Backend basics, final assessment |

Advanced topics (Redis, Kafka, Kubernetes, Jenkins, microservices, distributed systems) are intentionally left for November.

## Usage
Open `index.html` in a browser, or host it with GitHub Pages. Progress is stored in `localStorage`, so each browser keeps its own copy; use "Copy backup code" to move it between devices.
